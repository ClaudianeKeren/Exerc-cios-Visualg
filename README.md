# Exercícios de Lógica de Programação - VisuAlg

Meus exercícios práticos de lógica de programação desenvolvidos no VisuAlg.

## 📂 Exercícios
* **Exercicio CNH Visual:** Algoritmo que verifica se a pessoa pode tirar a CNH com base na idade.
* **Exercicio Media Notas:** Algoritmo que calcula a média de duas notas e mostra se o aluno foi Aprovado ou Reprovado.
